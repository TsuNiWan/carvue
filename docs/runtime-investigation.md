# 執行期設計與檢查重點

載入以 AbortController 與遞增序號隔離舊請求；解析後檢查身分與素材契約，過期結果立即釋放。成功預編譯及首幀後才開放操作。載入失敗可重試或返回總覽。

離開展示釋放關節、幾何、材質、貼圖、解碼影像、BVH、環境圖、陰影與 WebGL renderer，並移除事件與繪製循環。頁面隱藏暫停 RAF；恢復時重設時間基準。WebGL context 遺失停止載入與互動並提示重新整理。

情境以實際經過時間推進，機構與鏡頭各有獨立過渡。熱點使用 BVH 加速遮擋判定；資源是否回到基準由重複切車及長測驗證，不僅以呼叫 dispose 作結論。

詳細檢查結果見 verification.md；開發環境會提供 renderer-diagnostics，正式環境不輸出測試診斷面板。
