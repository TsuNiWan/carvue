## 執行期審查

- `loadVehicle.ts` 在下載、解析與預編譯階段處理取消；過期請求不覆蓋新車。準備過程取消會釋放材質，使 Three.js 預編譯輪詢能結束。
- `VehicleViewer.vue` 使用序號與 AbortController 雙重檢查；離開、context 遺失與頁面隱藏分別處理載入與 RAF。鍵盤與面板不依賴熱點才能操作。
- `assetRig.ts` 校驗素材身分、七個獨立關節與燈組；釋放幾何、材質、貼圖、影像與 BVH，dispose 可重複呼叫。
- `transition.ts` 從目前進度反向，行程時間依剩餘距離縮短；機構展示維持車門 1.1 秒、後廂 1.4 秒。
- 路由採 Hash，靜態產物使用相對路徑；根目錄與專案子目錄另做正式建置檢查。

上述判讀由既有回歸與新版素材契約交叉驗證；實際執行狀態見 [驗證紀錄](verification.md)。截至目前未發現額外需要改寫主要執行流程的發布阻擋問題。

首次完整回歸的 Edge 在沙箱內無法啟動；最小啟動檢查確認一般權限可用後，以同一套測試在沙箱外重新驗證。原始失敗摘要與後續重跑結果均保留，合併結果以每一案例最近一次執行為準。隱私處理詳見 [公開檔案檢查](privacy-review.md)。

## 保留限制

- 實車外觀權利仍未完整確認；去品牌、刪除參考資料、公開原始碼均不代替授權。
- 模型可見內部為展示用途近似建模，並非精確實車結構。
- Three.js 分包仍高於 Vite 的 500 kB 提示門檻；透過按需載入與實機冷載指標驗證使用體驗，不把建置警告隱藏。
- `src/three/vehicle.ts` 保留既有程序模型與測試，正式展示使用 GLB 適配層；本次未擴大刪除原有模組。
- 機密掃描檢查已知格式與私人路徑，另檢視圖片；此結果不等於對所有未知格式的絕對保證。
