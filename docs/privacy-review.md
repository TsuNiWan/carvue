# 公開檔案隱私檢查

## 檢查範圍

發布前掃描 Git 實際暫存的位元組，包含程式、文件、JSON、GLB、Blender 來源與圖片；以 UTF-8 及 UTF-16LE 檢查個人家目錄、憑證與私鑰格式。提交使用公開 GitHub 帳號及 GitHub noreply 信箱。

## 已處理項目

- 五份 Blender 來源的檔案瀏覽器緩衝區原本保留本機目錄；已清除殘留位元組並儲存為相對目錄。建模腳本共用同一儲存流程，避免重新匯出時再帶入。
- 可編輯來源沒有打包參考照片、連結外部資料庫或內嵌腳本；GLB 沒有嵌入照片與車廠參考網址。
- 19 張公開 WebP 圖片沒有 EXIF、XMP 或註解。README 圖片由網站內容直接擷取，沒有桌面、位址列或檔案瀏覽器。
- 驗證報告只保留專案相對路徑與量測資料。硬體紀錄保留 CPU、GPU、記憶體與瀏覽器版本，不記錄電腦名稱、登入使用者或私人主機位址。
- 工具、依賴、原始 trace、快取、下載與本機驗證暫存檔不提交。`.env`、`.npmrc` 與本機設定目錄已加入忽略清單。
- GitHub 憑證由既有系統憑證管理器提供，不寫入專案、Git remote、命令參數或發布文件。

掃描器以隔離儲存庫的假資料驗證，5 個案例通過，包含 UTF-16 路徑、憑證格式、禁止入庫檔案，以及從最新版本刪除後仍可在歷史中被找出的資料。結果見 [掃描器驗證](evidence/privacy-scanner-check.json)。

第三方必要授權通知與官方工具下載網址予以保留。模型外觀權利範圍另見 [素材權利](../ASSET_RIGHTS.md)。

## 重現

變更加入暫存後執行 `node scripts/verification/staged-privacy.mjs`；使用 `--all` 可檢查整個 Git index，`--history` 檢查待發布 HEAD 的完整歷史。每個邏輯提交前執行掃描，最後再檢查完整提交內容與圖片。掃描結果位於本機忽略目錄 `artifacts/product/staged-privacy.json` 與 `history-privacy.json`，公開摘要隨發布驗證文件記錄。

本機應用程式另有自動工作快照參照，可能保留舊工作資料；它們不屬於本次 main 分支的歷史。發布明確指定 `main:main`，不使用 mirror 或推送其他參照；乾淨 clone 再確認只取得公開分支內容。
