# CARVUE UI／UX 規格

石墨色背景、青綠重點色與自製 C／V 字形圖示。總覽顯示五款中性車型卡片；展示頁以 3D 畫面為主、右側依部位操作。返回所有車款與車款切換皆支援鍵盤。

驗收解析度 1280×720、1920×1080；主要文字 16px，控制文字 14px，輔助文字至少 12px，主要點擊區至少 44px。窄螢幕提供車款預覽與桌機提示，不建立完整 WebGL 場景。

車門 1.1 秒、後廂 1.4 秒、照明 250ms、轉向 160ms、視角 400ms。方向燈每半週期 450ms，內含 50ms 過渡。機構動畫依剩餘行程反向，不排隊。減少動態偏好取消視角飛行、縮短照明與轉向；使用者主動觸發的開門仍保留可觀察行程。

車上熱點隨關節移動且遮擋時隱藏；面板保留等價操作。鏡頭拖曳中隱藏熱點，避免誤觸。滑鼠拖曳可接管視角動畫，鍵盤方向鍵旋轉、加減縮放、Home 重設鏡頭。

「重設視角」僅改變鏡頭；「重設展示」保留當前車款、模式與情境種類，重設其他控制。安全科技清楚標示通用示意，不與任何實車配備綁定。
